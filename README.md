# BlinkitDataAnalysis_UsingEXCEL

## 📊 Project Overview

This project focuses on analyzing Blinkit sales data using **Microsoft Excel**. The goal was to understand sales performance, product trends, customer preferences, and outlet performance through an interactive dashboard.

## 🎯 Objectives

The analysis was created to answer important business questions such as:

* Which item types generate the highest sales?
* How does fat content impact sales?
* Which outlet types perform better?
* How do sales vary by outlet size?
* Which outlet locations contribute the most to sales?
* How does outlet establishment year affect sales?
* Which product categories and outlets show stronger performance?

## 📌 Key KPIs

* **Total Sales**
* **Average Sales**
* **Number of Items**
* **Average Rating**

## 📈 Analysis & Visualizations

The dashboard includes analysis of:

* Fat Content
* Fat Content by Outlet
* Item Type
* Outlet Establishment
* Outlet Size
* Outlet Location
* Outlet Type

## 🛠️ Tools & Excel Features Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Cards
* Data Cleaning
* Data Analysis
* Interactive Dashboard

## 💡 Problems Solved

Through this project, I transformed raw Blinkit data into meaningful insights by:

* Identifying top-performing product categories
* Comparing sales across different outlet types and sizes
* Understanding the relationship between fat content and sales
* Analyzing outlet location performance
* Studying sales trends based on outlet establishment
* Creating an interactive dashboard for easier business analysis
